What is Base64?

Base64 is a way to encode binary data as plain text. It is commonly used to embed images, tokens, or binary payloads in text-based formats like JSON or HTML.

How it works

ToolHub encodes plain text to Base64 and decodes Base64 back to UTF-8 text using browser APIs. Validation is shown if the input is not valid Base64.

Example

Text Hello becomes SGVsbG8= when encoded, and decodes back to the original text.
