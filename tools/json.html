What is a JSON formatter?

A JSON formatter makes raw JSON easy to read by adding indentation and line breaks. A validator checks whether the JSON is syntactically correct before you use it in your app or API.

How it works

ToolHub parses the input in your browser. If the JSON is valid, it outputs a pretty-printed version or a minified version without extra whitespace. If not, the error location is shown.

Example

Input: {"name":"ToolHub","speed":"fast"} becomes a multi-line, indented JSON object for easy inspection.
