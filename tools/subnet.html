What is a subnet calculator?

A subnet calculator takes an IP address and a CIDR prefix length, then computes the network address, broadcast address, usable host range, and the number of usable hosts in that subnet.

How it works

The CIDR prefix defines how many bits are allocated to the network. ToolHub calculates the subnet mask, applies it to the IP, and then derives the broadcast address and host range from the remaining host bits.

Example

For 192.168.1.10/24, the network is 192.168.1.0, the broadcast is 192.168.1.255, and the usable range is 192.168.1.1–192.168.1.254.
