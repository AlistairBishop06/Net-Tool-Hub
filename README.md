# 🧰 ToolHub

ToolHub is a fast, modern, SEO-optimised collection of free online tools designed for developers, students, and everyday users.  
Built with simple, high-performance web technologies, it focuses on usability, speed, and scalability.

---

## 🚀 Live Demo
[Visit the site](https://nettoolhub.vercel.app/)

---

## ✨ Features

- ⚡ Instant, live results (no reloads)
- 📱 Fully responsive (mobile-friendly)
- 🔍 SEO-optimised tool pages
- 📋 One-click copy buttons
- 🌙 Clean dark UI
- 🔗 Tool linking for better navigation
- 💰 Ready for monetisation (ads support)

---

## 🧰 Available Tools

### 🔹 Subnet Calculator
- Input IP address + CIDR
- Outputs:
  - Network address
  - Broadcast address
  - Usable host range
  - Total usable hosts
- Includes binary visualisation

---

### 🔹 JSON Formatter & Validator
- Format messy JSON into readable structure
- Validate JSON instantly
- Highlight errors clearly

---

### 🔹 Base64 Encoder / Decoder
- Encode text to Base64
- Decode Base64 back to text
- Useful for developers and API work
